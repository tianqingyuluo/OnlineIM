# v1 - 表情包系统（自定义表情，每人上限 100 张）

## 背景

IM 社交属性需要自定义表情。当前消息体支持文本，但无表情资产管理体系。本任务新增"我的表情包"：每个用户可上传图片作为自定义表情，上限 100 张，发消息时可插入引用表情。

## 用户旅程

> 原 PRD 此节为待头脑风暴的占位符。2026-10-21 按 tianqingyuluo 给出的 Step 4 要求（提案 A：每人上限 100 张）补全如下，作为 v1 范围。表情商店 / 共享表情包、分组、重命名、服务端转码 GIF 不在本次范围。

1. 用户在私聊或群聊（桌面 / 手机布局）点击输入区工具栏的笑脸按钮，表情面板底部有两个标签：“系统表情”（原 Unicode 表情，点击插入输入框）和“我的表情”。
2. “我的表情”标签显示已收藏的表情网格和“已用 / 上限”（如 `12/100`），第一个格子是“+”：选择 PNG / JPG / GIF 图片上传后立即出现在最前面。
   - GIF 动图原样保存并保持动画，必须不超过 2MB、1024×1024；
   - 静态图超过 1024 像素或 2MB 时由服务端自动等比缩小（源文件不超过 10MB）；
   - 格式不支持、太大、损坏、重复添加同一张图时给出中文提示；
   - 已有 100 个时提示“表情数量已达上限（100 个），请先删除一些再添加”，不会上传。
3. 点击某个表情立即作为表情消息发送（无需再点发送），面板收起；对方 / 群成员通过 WebSocket 实时收到。
4. 表情消息不套气泡，按原比例显示较大的图片（长边约 140px），GIF 自动播放；可以被引用回复、撤回。
5. 在聊天中右键（手机长按）收到的图片消息或表情消息，选择“添加到表情”，即保存到自己的收藏（服务端复制一份，原发送者删除不影响）；重复添加、超出上限给出提示。只能发送自己收藏中的表情，别人的表情需要先添加。
6. 点击“管理”进入管理模式：每个表情右上角可删除，左上角“移到最前”调整顺序；点击“完成”退出。删除只影响收藏，已发送的历史消息仍能显示。
7. 会话列表预览 `[表情]`，引用预览 `[表情]`；历史记录、刷新后、换设备登录后表情和收藏列表一致（收藏存服务端）。

## 需求

- 存储：MongoDB 集合 `user_emojis`（`emo_<32 hex>`、owner、对象键、url、名称、mime、大小、宽高、是否动图、帧数、内容 SHA-256、排序值、来源），索引 `(ownerId, sortOrder)` 与唯一 `(ownerId, contentHash)`；文件经 `FileStorageService` → `OSSAdapterFactory` 写入对象存储，对象键 `chats/emojis/yyyyMM/<随机>.<png|jpg|gif>`。
- `EmojiController`（`/api/v1/emojis`）：列表、上传、从消息收藏、删除、排序（完整顺序）。
- 限制全部可配置（`im.emoji.*`）：数量 100、GIF/结果大小 2MB、静态源图 10MB、边长 1024、帧数 300、格式 png/jpeg/gif。
- 消息体：`message_type=emoji`（`sticker` 同义），客户端只需提交 `emoji_id`，服务端校验归属并填充 `url`、尺寸、`animated` 等；已登记到 `docs/ws-protocol-registry.md`“自定义表情消息”。
- 客户端：表情面板“我的表情”标签 + 上传 / 管理（删除、移到最前）、表情消息渲染、“添加到表情”右键 / 长按菜单、`[表情]` 预览。

## e2e 测试场景

与上方用户旅程编号对应（部署验收脚本 `test/e2e-test.mjs --emoji` 与 `test/ui-step4.mjs`，不在仓库内）：

- 旅程 2（添加）：上传 PNG / JPG / 动图 GIF 成功，GIF 原样保存且 `animated=true`；大图自动缩小；拒绝 WebP/SVG（415）、损坏（400）、超大 GIF（413）、超尺寸 GIF（400）、重复（409）、未登录（401）；上传到第 100 个后第 101 个返回 409 且提示上限；对象在 RustFS 中。
- 旅程 3/4（发送与展示）：私聊经 WS、群聊经 WS 与 HTTP 发送；对方实时收到服务端填充的内容；伪造 url 被忽略；发送他人或不存在的表情被拒（WS ERROR 400 / HTTP 400）；历史可查；真实浏览器中表情无气泡、GIF 动画在播放（帧在变化）。
- 旅程 5（收藏）：接收方把收到的图片消息和表情消息添加到表情，得到新的对象；非会话成员 / 撤回消息 404；文本消息 400；右键 / 长按菜单可用。
- 旅程 6（管理）：删除他人表情 404；删除后历史消息仍可显示；排序必须是完整排列；“移到最前”后顺序持久化。
- 旅程 7（预览）：会话列表 `[表情]`，引用预览 `[表情]`；刷新后一致。
