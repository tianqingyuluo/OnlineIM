# v1 - 消息转发

## 背景

用户需要把一条消息（文本/图片/文件/语音等）转发到另一个会话（私聊或群聊），形成新的消息而保留原内容。当前无转发能力，用户只能复制粘贴，多媒体消息无法转发。

## 用户旅程

> 原 PRD 此节为待头脑风暴的占位符。2026-10-22 按 tianqingyuluo 给出的 Step 6 要求（单条 / 多条、一次转给多个好友或群、逐条与合并转发、媒体按引用复用、标注“转发自”、会话列表预览）补全如下，作为 v1 范围。转发到群不会 @ 任何人；“去除转发标识”、转发时附言、转发到非好友 / 未加入的群、转发给自己（文件传输助手）不在本次范围。

1. 用户在私聊或群聊中右键（手机长按）一条消息，菜单出现“转发”与“多选”；已撤回、发送中或发送失败的消息不能转发。
2. 选“转发”：打开目标选择器，列出好友（显示备注 / 昵称）与自己所在的群，可搜索（备注、昵称、用户名、群名），可多选，最多 9 个会话；手机上全屏显示。
3. 点“发送”：每个目标里出现一条由自己发出的新消息，内容和类型与原消息相同（文本 / 图片 / 文件 / 语音 / 表情 / 聊天记录），气泡上方显示“转发自 原作者”；图片、文件、语音、表情直接引用原文件，不重新上传。提示“已转发”或“已转发到 N 个会话”。
4. 选“多选”：进入多选模式，当前消息被选中，点击其他消息切换选中（不可转发的消息不能选），底栏显示“已选 N 条”与“逐条转发 / 合并转发 / 取消”。
5. 逐条转发：选中的消息按原顺序在每个目标里各成为一条新消息（最多 30 条）。
6. 合并转发：每个目标里只出现一条“聊天记录”卡片，标题为“我和对方的聊天记录”或“群聊“群名”的聊天记录”，显示前 3 条摘要与条数（最多 100 条）；点开卡片查看全部消息（发送者、时间、内容），其中的图片可预览、文件可下载、语音可播放、表情可显示、嵌套的聊天记录可继续打开。
7. 接收方（好友或群成员）实时收到新消息；会话列表预览显示文本内容或 [图片] / [文件] / [语音] / [表情] / [聊天记录]，刷新后不变；历史记录中转发标识与卡片保持。
8. 转发者自己的会话列表中目标会话立即更新预览；若当前正打开目标会话，新消息直接出现在消息列表。
9. 越权或失效时整体拒绝且不产生任何消息，并提示原因：不是来源会话的参与者、消息不存在、消息已撤回、目标不是好友、目标群未加入、超出数量上限。
10. 修复：私聊输入框选择 emoji 时插入到光标处（此前总是插到开头）。

## 需求

- 新增转发能力：选定原消息 + 目标会话 → 在目标会话产生新消息，保留原 contentType 与内容载体。
- 多媒体转发优先引用 url（不重复存储），具体策略以结论为准。（结论：按 `file_id` 引用原上传对象，服务端从上传记录重新填充元数据。）
- 溯源标识（转发自谁/原会话）按结论决定是否展示。（结论：展示“转发自 原作者”，不展示原会话。）
- 客户端：转发菜单、目标选择器、逐条/合并转发 UI。

## e2e 测试场景

> 原为占位符，按上方用户旅程补写（2026-10-22）。自动化脚本：`test/e2e-test.mjs --forward`（== 16 节，可单独运行）与 `test/ui-step6.mjs`（真实浏览器，桌面 + 手机）。

1. （旅程 3、7）A 把与 B 私聊中的文本 / 图片 / 文件 / 语音 / 表情逐条转发给好友 C 和群 G：C 与 G 的在线成员实时收到 `PRIVATE/GROUP_MESSAGE_RESPONSE`，类型与内容相同、发送者为 A、`forwarded_from` 为原作者；媒体 `file_id` / `url` 与原消息相同且对象仍在存储中可下载；历史接口返回相同字段；会话预览为对应文本或 [图片] 等。
2. （旅程 5）多条逐条转发按 `seq_id` 顺序生成；同一 `client_request_id` 重试不重复生成、不重复投递。
3. （旅程 3）转发链：C 再把收到的转发消息转给别人，`forwarded_from` 仍是最初作者；群消息转发到私聊不带 `at_users`。
4. （旅程 6）合并转发到 C 与 G：各生成一条 `chat_record`，标题、条数、条目（发送者名、类型、内容、媒体元数据）正确；预览为 [聊天记录]；聊天记录可以再次被转发（逐条与合并嵌套）。
5. （旅程 9）拒绝：非参与者（陌生人用 A 的私聊会话 / 未加入的群作为来源）403；消息不存在或属于其他会话 404；已撤回 409；目标非好友 403；目标群未加入（含已退群）403；给自己、空列表、超出上限、未知 mode 400；拒绝后目标会话无新消息。
6. （旅程 1–8，UI）桌面与手机：右键 / 长按出现“转发”“多选”；选择器搜索与多选；逐条转发后接收方页面实时出现带“转发自”的消息、列表预览正确；多选合并转发后卡片显示并可打开查看图片等条目；无 WS ERROR 帧。
7. （旅程 10，UI）私聊输入框中把光标移到中间后选 emoji，emoji 插入光标处。
