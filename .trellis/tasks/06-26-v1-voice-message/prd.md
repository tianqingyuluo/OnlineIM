# v1 - 语音消息

## 背景

IM 需要语音消息（按住录音、松开发送）。当前消息体无语音类型。本任务新增语音消息：客户端录制 → 上传 OSS → 消息体 `contentType=VOICE` + `url` + `duration`，对端点击播放，列表展示波形/时长。

## 用户旅程

> 2026-10-21 与 tianqingyuluo 确认的 v1 范围（Step 3）。波形、未读红点、顺序播放、听筒切换、ASR、服务端转码不在本次范围。

1. 用户在私聊或群聊（桌面 / 手机布局）点击输入区工具栏的麦克风按钮：
   - **点击**：开始录音，显示红点、计时（`00:05 / 01:00`）和进度条，以及“取消”“发送”按钮；
   - **按住**（≥0.45 秒）：按住说话，松开发送；松开前手指移出按钮范围则取消。
2. 首次录音时浏览器请求麦克风权限；拒绝、无设备、设备被占用、非安全上下文（非 HTTPS/localhost）时给出对应中文提示，不进入录音状态。
3. 录音格式由浏览器 MediaRecorder 决定，优先 `audio/webm;codecs=opus`（其次 ogg/opus、mp4），32 kbit/s；不做服务端转码。
4. 录满 60 秒自动结束并发送；短于 1 秒提示“说话时间太短”并丢弃。
5. 结束后立即上传（显示上传进度，可取消），成功后发送 `message_type=voice` 消息；对方通过 WebSocket 实时收到。
6. 语音气泡显示播放/暂停按钮、时长（`12″`，播放中显示当前进度 `00:03`）和可点击定位的进度条；气泡宽度随时长增长；同一时间只播放一条语音。
7. 会话列表预览 `[语音]`，引用预览 `[语音 00:12]`；历史记录可回放。

## 需求

- 消息体：`message_type=voice`，`content` 为服务端生成的媒体 JSON（`file_id`、`url`、`mime`、`size`、`duration_ms`、`duration`），已登记到 `docs/ws-protocol-registry.md`“语音消息”。
- 上传复用 Step 2 管线（`POST /api/v1/messages/upload`，`FileStorageService` → `OSSAdapterFactory`），`type=voice`，对象键 `chats/voices/yyyyMM/<随机>.<ext>`。
- 格式按内容识别：webm/ogg（opus、vorbis）、mp4/m4a、mp3、wav；不转码。时长优先服务端解析，解析不到才用客户端上报值并校验码率合理性；默认 60 秒上限、0.5 秒下限、5MB 上限，均可配置（`im.upload.voice-*`）。
- 播放进度：客户端进度条 + 点击定位（文件代理支持 Range）。未读红点、顺序播放、波形、听筒切换、ASR：v1 之后。
- 客户端：录制 UI（点击 / 按住）、权限异常提示、播放器、进度。

## e2e 测试场景

与上方用户旅程编号对应（部署验收脚本 `test/e2e-test.mjs --voice` 与 `test/ui-step3.mjs`，不在仓库内）：

- 旅程 1/4/5（录音与发送）：真实 Chromium + 假麦克风，点击录音（计时递增）→ 发送；按住说话松开发送；按住后移出再松开取消；取消按钮；不足 1 秒提示并不发送；桌面与手机布局。
- 旅程 2（权限）：拒绝麦克风权限时显示中文提示，不出现录音面板。
- 旅程 3（格式）：ffmpeg 生成的 webm/ogg/m4a/mp3/wav 与 Chromium MediaRecorder 录制的 WebM 上传成功，按内容识别 MIME、服务端解析时长；分片 MP4 使用校验后的客户端时长。拒绝伪造内容/视频（415）、损坏/超长/太短/时长不符（400）、超过 5MB（413）、未登录（401）。
- 旅程 5（投递）：私聊经 WS、群聊经 HTTP 发送；对方/群成员经 WS 实时收到；只能引用本人的语音上传；类型不匹配被拒；历史可查；对象在 RustFS；代理返回 `audio/*` 且支持 Range。
- 旅程 6（播放）：对方点击播放 → 播放中、进度前进、可暂停、播放结束复位；浏览器 Web Audio 能解码出非静音音频。
- 旅程 7（预览）：会话列表 `[语音]`，引用预览 `[语音 00:SS]`。

## 测试范围

- 后端单测：`AudioProbeTest`（各格式识别、时长解析、损坏/伪造/视频）、`ChatMediaServiceTest`（语音上传/限制/时长策略/引用校验）、`FileProxyControllerTest`（音频类型、Range 解析）、`MessageReplyServiceImplTest`（引用预览）、`MessageControllerTest`（时长参数）。
- 前端单测：录音控制器（时长、太短、60 秒自动结束、权限错误文案）、语音气泡（播放/暂停/单实例）、录音按钮权限提示、自动滚动、语音工具函数。
- 部署验收：上述 e2e 与真实浏览器脚本。
